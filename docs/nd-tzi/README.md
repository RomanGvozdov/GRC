# Каталог НД ТЗІ 3.6-006-24 та шаблони базових профілів

Покладіть сюди вихідні Word-файли (.docx):

- текст НД ТЗІ 3.6-006-24 (перелік вимог);
- шаблони базових профілів захищеності (конфіденційна / службова інформація).

З них генерується JSON для імпорту в систему (сторінка «Каталоги → Імпорт з JSON»)
у форматі:

```json
{
  "code": "nd-tzi-3-6-006-24",
  "name": "НД ТЗІ 3.6-006-24",
  "version": "2024",
  "requirements": [
    {"code": "...", "title": "...", "description": "...", "profiles": ["confidential"]},
    {"code": "...", "title": "...", "profiles": ["service"]},
    {"code": "...", "title": "...", "profiles": ["confidential", "service"]}
  ]
}
```

`profiles` визначає, до яких базових профілів належить вимога; порожній список —
вимога застосовна до всіх систем. Gap-аналіз і SoA для ІКС з типом профілю
«конфіденційна» або «службова» автоматично враховують лише застосовні вимоги.
